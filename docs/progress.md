## 알려진 제약

- iOS 홈 위젯 없음 (WidgetKit 별도 구현 필요)
- 홈 위젯과 스플래시는 다크 모드에서도 라이트 색
- 날짜가 바뀐 뒤 위젯 갱신은 최대 1시간 늦을 수 있음
- 앱 아이콘·로고 적용. 빈 화면 일러스트·달력 아이콘은 X 상자 자리 표시, 스플래시는 '내곁의' 로고
