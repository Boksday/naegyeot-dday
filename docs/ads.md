# 광고 배치

광고 SDK는 아직 연결하지 않았다. 화면에는 점선 상자(`src/components/AdBannerSlot.tsx`)로 자리만 잡아 두었다. 제공자는 미확정이며 AdMob이 후보다.

## 배너 위치

| 화면 | 위치                                   | 비고                         |
| ---- | -------------------------------------- | ---------------------------- |
| 목록 | 화면 맨 아래 고정, 내비게이션 바 위    | + 버튼은 배너 위로 24dp 띄움 |
| 상세 | 스크롤 맨 끝, 수정·삭제 버튼 아래 32dp | 버튼과 붙지 않게 간격 유지   |

자리 높이는 60dp. 표준 배너(320×50)와 적응형 배너의 높이 변화를 흡수한다.

## 넣지 않는 곳

- 디데이 입력 화면: 저장 버튼과 가까워 오클릭 위험
- 날짜 선택 시트, 삭제 확인 창
- 분류 관리 화면: 삭제 버튼이 반복되는 목록
- 홈 위젯, 알림

## 연결할 때 확인할 것

- 개발 중에는 공식 테스트 광고 ID만 쓴다.
- 광고 로드 실패·오프라인이어도 화면 배치가 깨지지 않게 자리를 유지하거나 접는 규칙을 정한다.
- 전면 광고는 쓰지 않는다. 쓴다면 저장 직후처럼 흐름이 끝나는 지점에 한정하고 빈도를 제한한다.
- 개인정보처리방침, 스토어 데이터 보안 신고, 동의(UMP) 처리, `app-ads.txt`
- Pro 구매자는 광고 자리를 숨긴다(docs/pro.md).
