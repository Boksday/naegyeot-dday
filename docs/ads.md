# 광고

AdMob 배너를 `react-native-google-mobile-ads`(17.2)로 연결했다. 실제 AdMob 계정·광고 단위는 아직 없고 구글 공식 테스트 ID로 동작을 확인했다.

## 설정 값 (.env, 커밋하지 않음 · .env.example 참고)

| 값                                                                 | 쓰이는 곳                                             | 비었을 때                            |
| ------------------------------------------------------------------ | ----------------------------------------------------- | ------------------------------------ |
| `ADMOB_ANDROID_APP_ID`, `ADMOB_IOS_APP_ID`                         | 네이티브 빌드(매니페스트·Info.plist), `app.config.js` | 구글 테스트 앱 ID                    |
| `EXPO_PUBLIC_ADMOB_BANNER_ANDROID`, `EXPO_PUBLIC_ADMOB_BANNER_IOS` | 앱 번들(배너 단위 ID)                                 | 운영 빌드에서 광고를 띄우지 않음     |
| `EXPO_PUBLIC_ADMOB_USE_TEST_IDS=1`                                 | 운영 빌드에서 테스트 광고 강제                        | 확인용 빌드에만 쓰고 배포하지 않는다 |

- 개발 빌드는 항상 테스트 광고 단위를 쓴다. 실제 광고를 직접 눌러 시험하지 않는다.
- 앱 ID를 바꾸면 `npx expo prebuild` 후 다시 빌드해야 한다. 배너 단위 ID는 번들만 다시 만들면 된다.

## 동작

- 앱 시작 시 `AdsConsent.gatherConsent()`로 동의(UMP)를 확인하고, 광고 요청이 가능할 때만 SDK를 초기화한다. 광고 단위 ID가 없으면 동의 창도 띄우지 않는다.
- 동의가 필요한 지역이면 설정 화면에 "광고 개인정보 설정"이 나타난다.
- `delayAppMeasurementInit`을 켜서 동의 전 측정을 늦춘다.
- 배너를 못 불러오거나 광고를 띄울 수 없으면 자리를 차지하지 않는다. 핵심 기능은 광고와 무관하게 동작한다.

## 배너 위치

| 화면 | 위치                                | 비고                                                  |
| ---- | ----------------------------------- | ----------------------------------------------------- |
| 목록 | 화면 맨 아래 고정, 내비게이션 바 위 | + 버튼은 목록 영역 아래쪽에 붙어 배너와 겹치지 않는다 |
| 상세 | 화면 맨 아래 고정, 내비게이션 바 위 | 스크롤 끝의 수정·삭제 버튼과 48dp 띄움                |

- 크기: `LARGE_ANCHORED_ADAPTIVE_BANNER`(기존 `ANCHORED_ADAPTIVE_BANNER`는 라이브러리에서 지원 중단 예정). 실기기(Z Flip6)에서 높이 약 129dp.

## 넣지 않는 곳

- 디데이 입력 화면: 저장 버튼과 가까워 오클릭 위험
- 날짜 선택 시트, 정렬 시트, 삭제 확인 창
- 분류 관리·설정 화면
- 홈 위젯, 알림
- 전면 광고는 쓰지 않는다.

## 출시 전 남은 일

- AdMob 계정·앱 등록, 배너 광고 단위 2개(Android·iOS) 발급 후 `.env`에 입력
- AdMob에서 GDPR 메시지(동의 양식) 게시
- `app-ads.txt`를 개발자 웹사이트에 게시, 스토어 개발자 웹사이트 등록
- 개인정보처리방침에 광고 SDK의 데이터 수집(광고 ID 등) 명시, Play 데이터 보안 양식 작성
- Pro 구매자는 광고를 숨긴다(docs/pro.md)
