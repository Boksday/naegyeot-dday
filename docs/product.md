# 내곁의 디데이 — 제품 정의

## 확정 사항

- 브랜드: 내곁의
- 앱 이름: 내곁의 디데이
- 식별자(Android/iOS): `com.naegyeot.dday`
- 출시 순서: Android 먼저, iOS 대응 설계
- 수익 모델: 광고 (제공자 미확정, AdMob 후보)

## MVP 범위

- 디데이 추가·수정·삭제, 목록 보기
- 분류: 기본 연인·개인·업무. 사용자가 추가(이름·색 8종)·삭제 가능, 최대 12개. 삭제하면 그 분류의 디데이는 남은 첫 분류로 옮김
- 목록에서 분류별로 걸러 보기, 분류별 색상
- 목록 정렬: 가까운 순(기본)·직접 정렬·최근 추가 순·이름순. 직접 정렬은 카드를 길게 눌러 끌어서 바꾼다. 고른 정렬은 유지된다
- 날짜 선택: 년·월·일 휠 시트 (Android·iOS 공통)
- D-n / D-Day / D+n 표시
- 기기 내부 저장 (서버 없음)
- 알림: 당일, 미리 알림(1·3·7일 전 중 선택). 오전 9시에 OS 로컬 알림으로 예약
- 매년 반복: 디데이별로 켜고 끌 수 있음. 지나면 다음 해 날짜로 계산. 2월 29일은 평년에 2월 28일
- 100일 단위 기념일: 디데이별 선택(기본 꺼짐). 기준일을 1일째로 세어 100일·200일… 상세 화면에 목록, 목록 카드에 다음 기념일 표시
- 홈 화면 위젯 (Android): 가까운 디데이 최대 3개, 탭하면 앱 열기

## 수용 기준

- 추가·수정·삭제한 디데이가 앱을 다시 켜도 유지된다.
- 분류가 없던 이전 버전 기록은 지워지지 않고 개인으로 옮겨진다.
- 분류를 삭제해도 디데이는 지워지지 않는다. 분류는 하나 이상 남는다.
- 저장 데이터가 손상되면 지우지 않고 오류 화면을 보여준다.
- 알림을 켠 디데이는 설정한 날 오전 9시에 알림이 온다. 수정·삭제하면 이전 예약이 사라진다.
- 위젯은 앱에서 저장하면 바로 갱신되고, 날짜가 바뀌면 1시간 이내에 갱신된다.

## 제외 범위 (첫 버전)

- 로그인, 동기화, 클라우드 백업
- 테마 상점, 인앱결제, 광고 제거 결제
- 분석 SDK

## 미정 사항

- Pro 범위·가격 ([pro.md](pro.md)), 무료 분류 개수
- 분류 이름 변경·순서 바꾸기

- 광고 제공자 및 광고 배치 위치
- 100일 단위 외 기념일(1주년 등) 포함 여부, 기념일 알림 여부
- 알림 시각 사용자 지정 여부
- iOS 홈 위젯 (WidgetKit 별도 구현 필요)
