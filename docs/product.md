# 내곁의 디데이 — 제품 정의

## 확정 사항
- 브랜드: 내곁의
- 앱 이름: 내곁의 디데이
- 식별자(Android/iOS): `com.naegyeot.dday`
- 출시 순서: Android 먼저, iOS 대응 설계
- 수익 모델: 광고 (제공자 미확정, AdMob 후보)

## MVP 범위
- 디데이 추가·수정·삭제, 목록 보기
- D-n / D-Day / D+n 표시
- 기기 내부 저장 (서버 없음)
- 알림: 당일, N일 전 (OS 로컬 알림 예약)
- 매년 반복: 디데이별로 켜고 끌 수 있음. 지나면 다음 해 날짜로 계산
- 100일 단위 기념일: D+100, D+200 등 시작일 기준 기념일 표시
- 홈 화면 위젯 (네이티브 별도 구현)

## 제외 범위 (첫 버전)
- 로그인, 동기화, 클라우드 백업
- 테마 상점, 인앱결제, 광고 제거 결제
- 분석 SDK

## 미정 사항
- 광고 제공자 및 광고 배치 위치
- N일 전 알림의 선택지 (예: 1·3·7일 전 고정 vs 자유 입력)
- 100일 단위 외 기념일(1주년 등) 포함 여부
- 위젯 크기와 표시 내용
