# Pro 업그레이드 아이디어

아직 구현하지 않은 제안이다. 무료 버전만으로 디데이 앱의 기본 쓸모(추가·알림·위젯)가 충분해야 광고 수익과 평가가 유지되므로, Pro는 "광고 제거 + 꾸미기 + 편의"로 묶는다.

## 추천 구성 (1차)

| 기능 | 무료                       | Pro                                                                    | 이유                                                          |
| ---- | -------------------------- | ---------------------------------------------------------------------- | ------------------------------------------------------------- |
| 광고 | 배너 있음                  | 없음                                                                   | 가장 이해하기 쉬운 구매 이유                                  |
| 분류 | 5개까지                    | 12개까지 + 분류별 아이콘 선택                                          | 이미 만든 분류 관리를 그대로 활용                             |
| 위젯 | 목록형 1종                 | 디데이 1개 크게(1×1·2×2), 특정 디데이 고정, 배경색 선택                | 디데이 앱 구매 동기 상위                                      |
| 알림 | 오전 9시, 미리 알림 1개    | 알림 시각 지정, 미리 알림 여러 개(30·100일 전 포함), 100일 기념일 알림 | 이미 있는 알림 예약 구조 확장                                 |
| 테마 | 라이트·다크(시스템 따르기) | 색 테마, 카드 배경 사진                                                | 꾸미기 수요(특히 연인 분류). 다크 모드는 무료로 제공하기로 함 |

## 2차 후보

- 공유 카드 이미지: 디데이를 인스타 스토리 크기 이미지로 저장. 무료는 워터마크, Pro는 제거 → 자연스러운 홍보 효과
- 상단바 상시 표시(Android 고정 알림)로 가장 가까운 디데이 보기
- 앱 잠금(생체 인증)
- 자동 백업(기기 클라우드)

## 무료로 두는 것이 나은 기능

- **파일 백업·복원**: 기록 유실은 평점에 치명적이라 무료가 맞다.
- **음력 날짜**: 한국에서 생일·제사 수요가 커서 무료로 두고 유입 무기로 쓰는 편이 낫다(구현 난도는 높음).

## 가격·결제

- 디데이 앱은 구독보다 **평생 이용권**(₩3,900~5,900 수준)이 거부감이 적다. 시장 가격은 출시 시점에 다시 확인한다.
- 구현: Google Play 결제(`expo-iap` 또는 `react-native-iap` 후보) + 구매 복원. 결제 대행 서비스(RevenueCat 등)는 매출 구간별 수수료가 생기므로 비용 확인 후 결정한다.
- 서버 없이 영수증 검증은 제한적이다. 소액 평생 이용권이면 클라이언트 확인으로 시작하고 위험을 기록한다.

## 정할 것

- 1차 Pro 범위와 가격
- 무료 분류 개수(현재는 모두 12개까지 허용)
